# 渭上公寓 · 日常，自有温度

一份以校园居住生活为主题的中英双语课程展示。页面将十组图片与文字整理为「初见渭上」「生活有序」「课余有光」三个章节，以奶油白、鼠尾草绿、宋体与英文衬线字体呈现日常空间。

公开网页：<https://meracle-sjj.github.io/weishang-apartment/>

公开仓库：<https://github.com/Meracle-sjj/weishang-apartment>

## 本地预览

无需安装依赖或构建。可直接打开 `index.html`，也可在项目目录运行：

```sh
python3 -m http.server 4173
```

然后访问 <http://localhost:4173/>。

## 文件与维护

- `index.html`：可直接修改的双语正文；每组用 `data-source` 保留原始图文编号。
- `styles.css`：响应式布局、设计颜色与本地字体声明。
- `script.js`：图片放大、当前章节指示与阅读进度；关闭脚本仍可阅读全文及打开原图。
- `assets/images/`：原始图片的发布副本，文件名编号与用户文案编号一一对应。
- `assets/fonts/`：自托管开放字体及 OFL 许可，来源与子集维护说明见该目录 `SOURCES.md`。
- `项目文案库.md` 与根目录数字图片：保留用户提供的原始材料。
- `CLAUDE.md` 与资源目录地图：记录结构、职责与内容边界。

修改中文后，应按 `assets/fonts/SOURCES.md` 说明补充中文字体子集，或使用系统宋体回退；不能依赖第三方在线字体请求。

## GitHub Pages 发布

使用 `main` 分支的仓库根目录作为发布源，`.nojekyll` 让 GitHub Pages 直接提供静态文件。更新静态文件后推送到 `main`，GitHub Pages 自动更新。全部资源使用相对路径，适配仓库子路径访问。
